# Шпаргалка: «Основы современных технологий»

Ответы на 34 вопроса к зачёту. У каждого вопроса две вкладки: **«Кратко»** (3–5 тезисов) и **«Подробно»** (развёрнутый ответ). Есть поиск, оглавление, тёмная тема, кнопка «Показать всё кратко / подробно». При печати выводятся оба варианта ответа.

**Открыть онлайн:** https://san4epons.github.io/shpargalka-osnovy-tehnologiy/

## iPhone: как пользоваться без интернета

1. Откройте ссылку https://san4epons.github.io/shpargalka-osnovy-tehnologiy/ именно в **Safari**.
2. Нажмите кнопку **«Поделиться»** (квадрат со стрелкой вверх) → **«На экран „Домой“»** → **«Добавить»**.
3. **Один раз** откройте шпаргалку с появившейся иконки, пока есть интернет: она сохранится в памяти телефона.
4. Готово: после этого шпаргалка открывается с экрана «Домой» и без сети, с вкладками, поиском и оглавлением.

> ⚠️ Не открывайте скачанный HTML-файл из приложения «Файлы». Там страница показывается без скриптов: все ответы выводятся сплошным текстом, а вкладки, поиск и переключатели не работают. Поэтому на iPhone нужен именно способ через экран «Домой».

Если шпаргалку обновили, откройте её с иконки при включённом интернете: новая версия подтянется в фоне и появится при следующем запуске.

## Android

Откройте ссылку в Chrome → меню «⋮» → **«Добавить на главный экран»** (или «Установить приложение»). Дальше так же: один раз открыть с интернетом, потом работает офлайн.

## Компьютер: скачать файл

Вся шпаргалка — это один файл `index.html`, интернет для него не нужен.

- **Самый простой способ:** [скачать файл напрямую](https://github.com/san4epons/shpargalka-osnovy-tehnologiy/releases/latest/download/index.html) и открыть его в любом браузере.
- **С сайта:** нажмите кнопку «Скачать для офлайн» под заголовком.
- **Архивом:** на этой странице нажмите зелёную кнопку **Code → Download ZIP**, распакуйте архив и откройте `index.html`.
- **Через GitHub:** откройте [`index.html`](index.html) в списке файлов и нажмите кнопку скачивания («Download raw file») справа над кодом.

## Файлы

- `index.html` — сама шпаргалка (всё встроено, внешних зависимостей нет);
- `manifest.webmanifest`, `sw.js`, `icons/` — нужны только для установки на экран «Домой» и работы без сети.
