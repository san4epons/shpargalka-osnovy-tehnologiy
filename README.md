# Шпаргалка: «Основы современных технологий»

Ответы на 34 вопроса к зачёту. У каждого вопроса две вкладки: **«Кратко»** (3–5 тезисов) и **«Подробно»** (развёрнутый ответ). Есть поиск, оглавление, тёмная тема, кнопка «Показать всё кратко / подробно». При печати выводятся оба варианта ответа.

**Открыть онлайн:** https://san4epons.github.io/shpargalka-osnovy-tehnologiy/

## Как скачать для просмотра без интернета

Вся шпаргалка — это один файл `index.html`. Внутри уже всё есть, интернет для него не нужен.

- **Самый простой способ:** [скачать файл напрямую](https://github.com/san4epons/shpargalka-osnovy-tehnologiy/releases/latest/download/index.html), затем открыть его в любом браузере.
- **С сайта:** откройте ссылку выше и нажмите кнопку «Скачать для офлайн» под заголовком.
- **Архивом:** на этой странице нажмите зелёную кнопку **Code → Download ZIP**, распакуйте архив и откройте `index.html`.
- **Только файл через GitHub:** откройте [`index.html`](index.html) в списке файлов и нажмите кнопку скачивания (стрелка вниз, «Download raw file») справа над кодом.

На телефоне: скачайте файл, затем откройте его из «Загрузок» или приложения «Файлы» в браузере.
